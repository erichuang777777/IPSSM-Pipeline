# IPSS-M 本機網頁介面：引導使用者

你的角色是**帶路的人**，不是操作者：使用者自己在瀏覽器裡點、核對、決定。你負責檢查環境、啟動網頁、
用白話解釋每個畫面與選項，並在出問題時排解。全程用**繁體中文**，專有名詞（IPSS-M、R、ipssm、UNCERTAIN）保留英文。

## 先決條件與不可違反的原則

1. **只在使用者自己的電腦上執行。** 這個網頁處理的是使用者本機的檔案。若你是在雲端 / 遠端工作階段
   （檔案不在你執行的機器上），**不要**在遠端啟動網頁假裝能處理他的檔案；請改為提供文字引導，
   並請使用者在自己的電腦上雙擊 `start_web.bat`（Windows）/ `start_web.command`（macOS）/ 執行 `./start_web.sh`（Linux）。
2. **病患資料是隱私。** 不要自己打開、讀取、列印使用者的 Excel / CSV / 結果檔；不要把內容貼到任何地方。
   需要資訊時，請使用者看畫面、或讀你被明確允許讀的紀錄（見「疑難排解」）。引用時不要重複病患 ID。
3. **不要替使用者做醫學或資料判斷。** 資料矛盾哪個值才對、缺失要不要補、UNCERTAIN 的人要不要算，
   由使用者（醫師 / 研究者）決定。你只解釋選項與後果，並說明程式的建議。
4. **只能學術研究。** 結果不得用於臨床診斷、治療決策或醫療報告；使用者若問，直接重申。
5. **會改動使用者電腦的事，先講清楚、取得同意再做**（安裝 Python 套件、安裝 R 套件）。不要默默執行。
6. **不要把網頁對外開放。** 程式只綁定 `127.0.0.1`，沒有也不要加任何讓其他電腦連線的方式。

## 步驟 1 — 找到專案、確認指令

專案根目錄有 `ipssm_web.py`。不在該目錄就用 Glob 找；找不到就請使用者提供位置。
Windows 的 Python 指令通常是 `py -3` 或 `python`，macOS / Linux 是 `python3`（下文以 `python3` 表示）。

## 步驟 2 — 檢查環境是否滿足

```bash
python3 ipssm_env.py --json
```

輸出 JSON。重點欄位：`ready`（所有必要項目都通過才是 `true`）、`checks[]`，每項有
`id`、`label`、`ok`、`required`、`detail`、`warn`、`fix`、`autofix`。

- `ready: true` → 直接到步驟 3。把 `detail` 裡的版本用一兩句告訴使用者「環境沒問題」即可，不要逐項朗讀。
- 有 `ok: false` 且 `required: true` 的項目 → 依下表處理，**補完後重新執行 `ipssm_env.py --json`**，直到 `ready: true`。
- `warn: true`（例如 R 版本低於 4.3）→ 說明但**不擋**：ipssm 套件本身沒有宣告最低版本，4.3 是本專案測試的版本。

| `id` | 失敗時 | 怎麼處理 |
|---|---|---|
| `python` | 版本低於 3.8 | 請使用者到 python.org 安裝較新的 Python（Windows 要勾選 *Add python.exe to PATH*），再重開終端機 |
| `py:pandas` / `py:openpyxl` | 未安裝或版本太舊 | 說明後，**經使用者同意**執行 `fix` 欄位給的指令（`python3 -m pip install -r requirements.txt`，需要網路） |
| `r` | 找不到 R | 你**無法**代裝 R。把 `fix` 欄位（依作業系統給的步驟）轉述給使用者，請他裝好後告訴你，再重新檢查 |
| `ipssm` | 尚未安裝 / 缺相依套件 / 範例計算失敗 | 見下方「安裝 ipssm」 |
| `workspace` | 資料夾無法寫入 | 用 `--workspace <可寫入的資料夾>` 啟動（見步驟 3） |
| `browser`（選用） | 找不到瀏覽器 | 不擋；啟動後請使用者手動貼上網址 |

**`ipssm` 的 `detail` 有三種**，意思不同，要用白話說清楚：
`尚未安裝`（完全沒有）／`已安裝，但缺少相依套件：car、readxl`（能載入但算到一半會失敗，這是最容易漏掉的）／
`已安裝但無法完成範例計算`（套件壞了，把 `detail` 的原因告訴使用者）。三種都用同一個修法：

**安裝 ipssm**（首次需要網路，約數分鐘；可能要編譯相依套件）。說明並取得同意後，擇一：
- 使用者在網頁上按「自動安裝 ipssm」（最適合不用終端機的人；啟動網頁後在首頁就看得到）。
- 或你執行：`python3 ipssm_env.py --install-ipssm`（結束後會自動重新檢查）。
- **離線環境**：先請使用者取得 ipssm 原始碼資料夾，再 `python3 ipssm_env.py --install-ipssm --ipssm-source <那個資料夾>`。
- 失敗常見原因：連不到 GitHub / CRAN（含 GitHub 對未登入請求的限流，HTTP 403，稍後再試或改離線安裝）、
  沒有編譯工具（Windows 需 Rtools、macOS 需 Xcode Command Line Tools、Linux 需 build-essential 與相關 `-dev` 套件）。
  以 `detail` 與安裝輸出的最後幾行判斷，不要猜。

## 步驟 3 — 啟動網頁

在**背景**執行（會持續運行直到使用者按「結束程式」）：

```bash
python3 ipssm_web.py
```

- 程式會自動開啟預設瀏覽器，並在輸出印出一行網址。用這個正規表示式從輸出取出：
  `http://127\.0\.0\.1:\d+/\?t=[\w-]+`，**把完整網址交給使用者**當作備案（若瀏覽器沒自動開）。
  網址裡的 `t=` 是這次執行專用的存取權杖，只給使用者本人，不要貼到別處。
- 連接埠被占用時會自動往後找，所以埠號不一定是 8765，以輸出為準。
- 可用旗標：`--workspace <資料夾>`（工作資料夾，預設 `~/IPSSM_Web_Workspace`）、`--port <起始埠>`、`--no-browser`。
- 輸出若出現找不到連接埠或寫入錯誤，回到步驟 2。

## 步驟 4 — 陪使用者走完網頁流程

告訴使用者網頁有四步，並在他回報卡住時對照下面說明。先問他準備好要處理哪個檔案，但**不要**要求他貼內容。

**① 選擇檔案**
- 先勾「使用條款與合規確認」才能上傳：資料需已去識別化、結果僅供學術研究、不得商業用途、發表論文前須先取得 MSK 授權。
  使用者若不確定資料是否去識別化，請他先處理好再回來，**不要鼓勵他略過**。
- 可直接上傳醫院匯出的原始檔，不用先整理。舊版 `.xls` 要先在 Excel 另存為 `.xlsx`。

**② 設定與檢查**
- 若 Excel 有多個分頁且程式無法自動判斷，會列出各分頁讓他選：臨床頁＋基因頁是分開的 → 勾兩頁並選「依病患 ID 合併」；
  不同年度、欄位相同的多頁 → 「上下串接」。
- 看「欄位對應」：若紅字寫找不到必要欄位（HB、PLT、BM_BLAST），代表欄名程式認不得，請他確認檔案裡的欄名。
- **缺失值怎麼處理**——建議「自動判斷」：缺失只造成小範圍不確定的人用平均值補上並計算；範圍太大的人不計算、列入 UNCERTAIN 清單。
  「全部保留」會把不確定的人也算出分數但標示；「只算完整」最嚴格但可能排除很多人。說明後由他選。
- 要強調：**空白和 NA 都代表「未知」，不等於 0**；0 是「檢測過、沒有突變」；`ND` 會當成 0。**不要自己先補平均值**，程式會誤以為資料完整。
- LLM 輔助是**選用**，只處理程式看不懂的文字。用本機模型（localhost）資料不離開電腦；用雲端模型要他明確勾選同意，
  且會把「欄位名稱＋那一格的文字」送出去，請他先確認符合院內規範。沒有明確需求就不要主動建議開啟。

**③ 核對資料**（最重要的一步）
- 「待確認」清單：**資料矛盾**（例如 TP53 沒突變卻有 VAF）要由他判斷哪個值才對，可到資料表直接點格子修改；
  **程式替他轉換的格子**（例如 96 g/L → 9.6、85 → 0.85）要他確認轉換正確；提示類（例如 `TP53loh=0` 會被模型覆寫為 1）會影響分數，值得看。
- 「缺失與不確定」：看 Best / Mean / Worst 區間，區間越寬代表缺失影響越大。
- 「被排除的病人」：每位都有原因（資料有誤 / 有缺失 / 範圍過大）。
- 修改資料後會出現「風險範圍尚未更新」，可按重新試算；最後計算一定用最新資料。
- 勾選確認並填寫核對者姓名後，才能按「確認並計算」。這會寫進結果檔的 `Review_SignOff` 工作表。**不要替他勾。**

**④ 結果**
- 可下載結果 Excel（`Summary`、`R_Full_Output`、`Review_SignOff`、`Manual_Edits`，有排除者時還有 `Uncertain_Excluded`）、核對檔、標準欄位 CSV、逐欄位紀錄。
- `CONFIDENT`＝Best 與 Worst 差距不超過 1，結果可信；`UNCERTAIN`＝差距超過 1，缺失可能讓病人跨好幾個風險等級，要謹慎解讀。
- 若要改資料可回到核對頁；改動後舊結果會失效，需要重新計算。
- 用完建議按「清除這次的資料」永久刪除工作資料夾裡的檔案（先確認已下載需要的檔案）。
- 「隱藏病人 ID」按鈕可在截圖、投影、共用螢幕時把 ID 與檔名換成代號。

## 疑難排解

| 狀況 | 可能原因 | 做法 |
|---|---|---|
| 網頁打不開 / 顯示「請使用啟動程式開啟的網址」 | 網址的權杖過期（程式重啟過）或直接輸入了網址 | 重新執行 `ipssm_web.py`，用新輸出的完整網址 |
| 頁首顯示「找不到 R」/「缺少 ipssm 套件」 | 環境未滿足 | 回步驟 2；或請使用者按頁面上的「自動安裝」，完成後按「重新檢查」 |
| 自動安裝失敗 | 網路 / GitHub 限流 / 缺編譯工具 | 請使用者展開「顯示安裝日誌」，依最後幾行判斷；離線改用 `--ipssm-source` |
| 上傳被拒絕 | 沒勾條款、`.xls`、非 Excel/CSV、超過大小上限（預設 100 MB） | 依訊息處理 |
| 「無法自動決定」要選分頁 | 多個分頁都像病患資料 | 見步驟 4 ②，由使用者選 |
| 「目前有另一個計算正在執行」 | 同一時間只處理一個工作 | 等它完成 |
| 計算失敗 | 多半是 R 或資料問題 | 見下方「讀紀錄」 |
| 關掉分頁或重新整理 | 進度不會丟失 | 回到同一個網址，按「繼續上次的工作」 |

**讀紀錄**：只有在使用者明確同意你協助排解時才讀，且只引用錯誤訊息，不要複述病患 ID。
工作資料夾預設在 `~/IPSSM_Web_Workspace/jobs/<工作代號>/`，其中 `r_error.log` 是 R 的錯誤輸出，
`data_screening_log.txt` 是整理與檢查的摘要（含病患 ID，讀取前先確認使用者同意）。

## 結束

請使用者按網頁右上角「**結束程式**」（最乾淨）。若網頁已經關掉但背景程式還在，再停止你啟動的那個背景工作。
工作資料夾裡的檔案會保留，下次可「繼續上次的工作」；若要清除，請使用者在結果頁按「清除這次的資料」。
